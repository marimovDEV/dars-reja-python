# dars-reja-python

O'qituvchilar va Python Backend o'quv markazlari uchun professional Dars Rejasi, Guruhlar Boshqaruvi va Dokumentatsiyalar Tizimi.

## 🚀 Texnologiyalar
- **Backend**: Python 3.11, Django, Django REST Framework, SQLite
- **Frontend**: React 18, TypeScript, TailwindCSS, Vite
- **Integratsiya**: Notion Sync, REST API

## 📋 Xususiyatlar
- 72 ta darsdan iborat professional Python Backend o'quv dasturi va dokumentatsiyasi
- Guruhlar boshqaruvi (yangi guruh yaratish, boshlanish sanasidan 72 dars kalendarini avtomatik hisoblash)
- Har bir guruh uchun dars holatlari (o'tildi, jarayonda, reja, qoldirildi) va izohlarni alohida yuritish
- Guruhlar monitori (Dashboard) va real-vaqt progres kuzatuvi
